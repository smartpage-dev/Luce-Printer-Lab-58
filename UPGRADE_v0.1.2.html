The helper accepted Runnable, but the preview and confirmation callbacks can throw checked exceptions. A private CheckedAction now expresses that contract; the existing click-time exception handler is retained.

NO APK INCLUDED

This is a source patch and complete build kit, not an Android installer. The local regression compiles the actual callback helper with minimal view doubles. It does not replace Android SDK compilation, lint, or hardware tests.
